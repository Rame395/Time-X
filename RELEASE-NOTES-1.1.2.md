# TIME-X Nepal — Premium Storefront 1.1.2

Requested storefront refinements:

- Premium success/error toast messages for add-to-cart and wishlist actions.
- Men/Women navigation no longer hijacks clicks with the taxonomy preview; clicking always opens the full page cleanly. Desktop hover preview remains available.
- Three-line navigation button is available at desktop, tablet, and mobile widths and opens the same full navigation menu.
- Removed footer contact-phone presentation and policy-page phone contact links.
- Homepage now has exactly six carried-brand logos/names: Timex, Lacoste, Guess, Lee Cooper, Calvin Klein, Tommy Hilfiger.
- Gallery filter bar remains synchronized/sticky with the fixed header while scrolling, including mobile header/search offsets.
- Product discount badges now show the calculated percentage (for example, 2000 vs 4000 displays `50% OFF`) instead of the generic `Sale` label.
- Admin Add/Edit Product forms include a live discount-banner preview based on Price and Compare-At Price.
- Mobile storefront has a persistent top search field and the six carried-brand names are shown with their logos in the scrolling brand section.
- Existing production Docker/PostgreSQL/Caddy deployment files remain unchanged.
